# Provider icon assets

These provider marks were copied from the locally installed Cherry Studio
desktop application's renderer assets at the user's request. They are used
only to identify the corresponding model provider in ScanSci.

All provider names, logos, and trademarks remain the property of their
respective owners. The application keeps a text fallback for providers that
do not have a matching local asset.

The `typesafe.png` mark is a local copy of the TypeSafe AI website favicon,
used for the JEV entry point in Model Services. It remains the property of
TypeSafe AI.
